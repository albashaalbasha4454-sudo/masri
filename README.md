# مطابخ الشرق

نظام مطابخ الشرق لإدارة نقطة البيع، الطلبات، الفواتير، المصروفات، العملاء، الخزينة، التقارير، وإغلاق الصندوق اليومي.

## بيانات التشغيل الافتراضية

- المدير: `admin`
- الكاشير: `cashier`

## القائمة الافتراضية

تم تجهيز النظام بقائمة يوم الجمعة 2026/5/1:

### قائمة السندويشات

- سندويش فلافل كبيرة
- سندويش مرتديلا كبيرة
- سندويش مرتديلا مع بيض كبيرة
- سندويش سجق كبيرة
- سندويش بطاطا مقلية كبيرة
- سندويش سودة دجاج كبيرة
- سندويش شيش طاووق كبيرة
- سندويش بيض مسلوق كبيرة
- سندويش بيض مقلي كبيرة

### قائمة الوجبات

- صحن فول باللبن
- صحن فول بزيت
- صحن حمص باللبن
- صحن حمص بزيت
- صحن فتة
- صحن فتة بسمنة
- صحن مسبحة حمص بالطحينة
- صحن بطاطا مقلية
- صحن فلافل
- صحن بيض مقلي
- صحن بيض مسلوق

الأصناف التي لم يتم تحديد سعرها بعد وُضعت بسعر `0` حتى يتم تعديلها من شاشة الأصناف داخل النظام.

## المتطلبات

- Node.js 22 أو أحدث
- مفتاح Gemini API عند استخدام خصائص الذكاء الاصطناعي

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local
npm run dev
```

ضع مفتاح Gemini داخل `.env.local` عند الحاجة:

```bash
GEMINI_API_KEY="YOUR_API_KEY"
```

## أوامر المشروع

```bash
npm run dev      # تشغيل بيئة التطوير
npm run build    # بناء نسخة الإنتاج
npm run preview  # معاينة نسخة الإنتاج
npm run lint     # فحص TypeScript
```

## النشر على GitHub Pages

تم تجهيز المستودع بملف GitHub Actions للنشر التلقائي:

`.github/workflows/deploy.yml`

عند الدفع إلى فرع `main`، يقوم GitHub Actions بتثبيت الحزم، بناء المشروع، ثم نشر مجلد `dist` على GitHub Pages.

قبل أول نشر، افتح إعدادات المستودع:

1. Settings
2. Pages
3. Source: GitHub Actions
